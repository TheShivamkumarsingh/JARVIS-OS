# 🤖 JARVIS OS

> A Modular AI-Powered Personal Assistant built with Python, Ollama, SQLite and modern AI Engineering principles.

---

## 🚀 About

JARVIS OS is an AI-powered personal assistant designed to evolve into a complete AI Operating System.

Unlike traditional chatbot projects, JARVIS OS focuses on:

- Modular Architecture
- Local Large Language Models (LLMs)
- Persistent Memory
- AI Memory Extraction
- Tool Calling
- Voice Assistant
- Vision
- Multi-Agent Systems

The long-term goal is to create an intelligent assistant capable of remembering information, using tools, reasoning about tasks, and helping with daily productivity.
